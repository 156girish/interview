	✅ 1. Find Largest Element
	🔹 Normal Approach (Sorting)
	int[] arr = {10, 20, 5, 40, 30};


	Arrays.sort(arr);


	System.out.println("Largest = " + arr[arr.length - 1]);

	Explanation:

	Sort the array.
	Last element is the largest.

	Time Complexity: O(n log n)
	Space Complexity: O(1)

	🔹 Optimized Approach (Single Traversal)
	int[] arr = {10, 20, 5, 40, 30};


	int largest = arr[0];


	for (int i = 1; i < arr.length; i++) {
		if (arr[i] > largest) {
			largest = arr[i];
		}
	}


	System.out.println("Largest = " + largest);

	Why better:

	Only one traversal.
	No sorting required.

	Time Complexity: O(n)
	Space Complexity: O(1)

	✅ 2. Find Second Largest
	🔹 Normal Approach (Sorting)
	int[] arr = {10, 20, 5, 40, 30};


	Arrays.sort(arr);


	System.out.println("Second Largest = " + arr[arr.length - 2]);

	Explanation:

	Sort array.
	Second last element is the second largest.

	Time Complexity: O(n log n)

	🔹 Optimized Approach
	int[] arr = {10, 20, 5, 40, 30};


	int largest = Integer.MIN_VALUE;
	int secondLargest = Integer.MIN_VALUE;


	for (int num : arr) {
		if (num > largest) {
			secondLargest = largest;
			largest = num;
		} else if (num > secondLargest && num != largest) {
			secondLargest = num;
		}
	}


	System.out.println("Second Largest = " + secondLargest);

	Why better:

	Finds both largest and second largest in one pass.

	Time Complexity: O(n)
	Space Complexity: O(1)

	✅ 3. Find Nth Largest
	🔹 Normal Approach (Sorting)
	int[] arr = {10, 20, 5, 40, 30};
	int n = 3;


	Arrays.sort(arr);


	System.out.println(n + "rd Largest = " + arr[arr.length - n]);

	Explanation:

	Sort array.
	Nth largest = arr[length - n].

	Time Complexity: O(n log n)

	🔹 Optimized Approach (Min Heap)
	int[] arr = {10, 20, 5, 40, 30};
	int k = 3;


	PriorityQueue<Integer> pq = new PriorityQueue<>();


	for (int num : arr) {
		pq.offer(num);


		if (pq.size() > k) {
			pq.poll();
		}
	}


	System.out.println(k + "rd Largest = " + pq.peek());

	Why better:

	Efficient for large arrays.
	No need to sort the entire array.

	Time Complexity: O(n log k)
	Space Complexity: O(k)

	✅ 8. Left Rotate by K
	🔹 Normal Approach (Extra Array)
	int[] arr = {1, 2, 3, 4, 5};
	int k = 2;


	k %= arr.length;


	int[] temp = new int[arr.length];


	for (int i = 0; i < arr.length; i++) {
		temp[i] = arr[(i + k) % arr.length];
	}


	System.out.println(Arrays.toString(temp));

	Time Complexity: O(n)

	🔹 Optimized Approach (Reversal Algorithm)
	int[] arr = {1, 2, 3, 4, 5};
	int k = 2;


	k %= arr.length;


	reverse(arr, 0, k - 1);
	reverse(arr, k, arr.length - 1);
	reverse(arr, 0, arr.length - 1);


	System.out.println(Arrays.toString(arr));


	static void reverse(int[] arr, int start, int end) {
		while (start < end) {
			int temp = arr[start];
			arr[start] = arr[end];
			arr[end] = temp;
			start++;
			end--;
		}
	}

	Why better:

	In-place rotation.
	No extra array.

	Time Complexity: O(n)
	Space Complexity: O(1)

	✅ 13. Container With Most Water
	🔹 Normal Approach (Brute Force)
	int[] height = {1,8,6,2,5,4,8,3,7};


	int max = 0;


	for (int i = 0; i < height.length; i++) {
		for (int j = i + 1; j < height.length; j++) {


			int area = Math.min(height[i], height[j]) * (j - i);


			max = Math.max(max, area);
		}
	}


	System.out.println(max);

	Explanation:

	Check every pair.

	Time Complexity: O(n²)

	🔹 Optimized Approach (Two Pointer)
	int[] height = {1,8,6,2,5,4,8,3,7};


	int left = 0;
	int right = height.length - 1;
	int max = 0;


	while (left < right) {


		int area = Math.min(height[left], height[right]) * (right - left);


		max = Math.max(max, area);


		if (height[left] < height[right]) {
			left++;
		} else {
			right--;
		}
	}


	System.out.println(max);

	Why better:

	Eliminates unnecessary comparisons.

	Time Complexity: O(n)
	Space Complexity: O(1)

	✅ 14. Longest Subarray with Given Sum
	🔹 Normal Approach
	int[] arr = {1,2,3,1,1,1,1};
	int target = 3;


	int maxLength = 0;


	for (int i = 0; i < arr.length; i++) {


		int sum = 0;


		for (int j = i; j < arr.length; j++) {


			sum += arr[j];


			if (sum == target) {
				maxLength = Math.max(maxLength, j - i + 1);
			}
		}
	}


	System.out.println(maxLength);

	Time Complexity: O(n²)

	🔹 Optimized Approach (HashMap - Works for Positive & Negative Numbers)
	int[] arr = {1,2,3,1,1,1,1};
	int target = 3;


	Map<Integer, Integer> map = new HashMap<>();


	int sum = 0;
	int max = 0;


	for (int i = 0; i < arr.length; i++) {


		sum += arr[i];


		if (sum == target)
			max = i + 1;


		if (map.containsKey(sum - target))
			max = Math.max(max, i - map.get(sum - target));


		map.putIfAbsent(sum, i);
	}


	System.out.println(max);

	Why better:

	Handles negative numbers also.

	Time Complexity: O(n)

	✅ 17. Product Except Self
	🔹 Normal Approach
	int[] arr = {1,2,3,4};


	int[] result = new int[arr.length];


	for (int i = 0; i < arr.length; i++) {


		int product = 1;


		for (int j = 0; j < arr.length; j++) {


			if (i != j)
				product *= arr[j];
		}


		result[i] = product;
	}


	System.out.println(Arrays.toString(result));

	Time Complexity: O(n²)

	🔹 Optimized Approach (Prefix & Suffix Products)
	int[] arr = {1,2,3,4};


	int n = arr.length;


	int[] result = new int[n];


	result[0] = 1;


	for (int i = 1; i < n; i++)
		result[i] = result[i - 1] * arr[i - 1];


	int suffix = 1;


	for (int i = n - 1; i >= 0; i--) {


		result[i] *= suffix;


		suffix *= arr[i];
	}


	System.out.println(Arrays.toString(result));

	Why better:

	No division used.
	Two linear traversals.

	Time Complexity: O(n)

	✅ 18. Kth Largest Element
	🔹 Normal Approach
	int[] arr = {3,2,1,5,6,4};


	int k = 2;


	Arrays.sort(arr);


	System.out.println(arr[arr.length - k]);

	Time Complexity: O(n log n)

	🔹 Optimized Approach (Min Heap)
	int[] arr = {3,2,1,5,6,4};


	int k = 2;


	PriorityQueue<Integer> pq = new PriorityQueue<>();


	for (int num : arr) {


		pq.offer(num);


		if (pq.size() > k)
			pq.poll();
	}


	System.out.println(pq.peek());

	Why better:

	Heap size remains k.
	Better for very large arrays.

	Time Complexity: O(n log k)

	✅ 19. Search in Rotated Sorted Array
	🔹 Normal Approach (Linear Search)
	int[] arr = {4,5,6,7,0,1,2};


	int target = 0;


	for (int i = 0; i < arr.length; i++) {


		if (arr[i] == target) {
			System.out.println(i);
			break;
		}
	}

	Time Complexity: O(n)

	🔹 Optimized Approach (Modified Binary Search)
	int[] arr = {4,5,6,7,0,1,2};


	int target = 0;


	int left = 0;
	int right = arr.length - 1;


	while (left <= right) {


		int mid = left + (right - left) / 2;


		if (arr[mid] == target) {
			System.out.println(mid);
			break;
		}


		if (arr[left] <= arr[mid]) {


			if (target >= arr[left] && target < arr[mid]) {
				right = mid - 1;
			} else {
				left = mid + 1;
			}


		} else {


			if (target > arr[mid] && target <= arr[right]) {
				left = mid + 1;
			} else {
				right = mid - 1;
			}
		}
	}

	Why better:

	Uses binary search on the sorted half of the rotated array.

	Time Complexity: O(log n)
	Space Complexity: O(1)

	✅ 35. Valid Parentheses

	String str = "()[]{}";


	while (str.contains("()") || str.contains("{}") || str.contains("[]")) {


		str = str.replace("()", "")
				 .replace("{}", "")
				 .replace("[]", "");

	Explanation:

	Time Complexity: O(n²)

	🔹 Optimized Approach (Stack)
	String str = "()[]{}";


	Stack<Character> stack = new Stack<>();


	for (char ch : str.toCharArray()) {


		if (ch == '(' || ch == '{' || ch == '[')
			stack.push(ch);


		else {


			if (stack.isEmpty()) {
				System.out.println(false);
				return;
			}


			char top = stack.pop();


			if ((ch == ')' && top != '(') ||
				(ch == '}' && top != '{') ||
				(ch == ']' && top != '[')) {


				System.out.println(false);
				return;
			}
		}
	}


	System.out.println(stack.isEmpty());

	Why better:

	Standard interview solution.

	Time Complexity: O(n)
	Space Complexity: O(n)

	✅ 37. Maximum Sum Subarray of Size K
	🔹 Normal Approach
	int[] arr = {2,1,5,1,3,2};


	int k = 3;
	int max = Integer.MIN_VALUE;


	for (int i = 0; i <= arr.length-k; i++) {


		int sum = 0;


		for (int j = i; j < i+k; j++)
			sum += arr[j];


		max = Math.max(max, sum);
	}


	System.out.println(max);

	Explanation:

	Calculate every window separately.

	Time Complexity: O(n × k)

	🔹 Optimized Approach (Sliding Window)
	int[] arr = {2,1,5,1,3,2};


	int k = 3;


	int sum = 0;


	for (int i = 0; i < k; i++)
		sum += arr[i];


	int max = sum;


	for (int i = k; i < arr.length; i++) {


		sum += arr[i] - arr[i-k];


		max = Math.max(max, sum);
	}


	System.out.println(max);

	Why better:

	Reuses previous window sum.

	Time Complexity: O(n)
	Space Complexity: O(1)

	✅ 38. Binary Search
	🔹 Normal Approach (Linear Search)
	int[] arr = {2,4,6,8,10,12};


	int target = 10;


	for (int i = 0; i < arr.length; i++) {


		if (arr[i] == target) {
			System.out.println(i);
			break;
		}
	}

	Explanation:

	Check every element one by one.

	Time Complexity: O(n)

	🔹 Optimized Approach (Binary Search)
	int[] arr = {2,4,6,8,10,12};


	int target = 10;


	int left = 0;
	int right = arr.length - 1;


	while (left <= right) {


		int mid = left + (right - left) / 2;


		if (arr[mid] == target) {
			System.out.println(mid);
			break;
		}


		if (arr[mid] < target)
			left = mid + 1;
		else
			right = mid - 1;
	}

	Why better:

	Divides the search space into halves each iteration.
	Works only for sorted arrays.

	Time Complexity: O(log n)
	Space Complexity: O(1)
