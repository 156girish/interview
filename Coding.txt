
	✅ 1. Reverse a String
	🔹 Normal Approach

	Convert string to char[]

	Loop from end to start

	Build new string

	String str = "hello";
	String rev = "";

	for (int i = str.length() - 1; i >= 0; i--) {
		rev += str.charAt(i);
	}
	System.out.println(rev);


	⏱ Time: O(n)
	📦 Space: O(n)

	⚠️ Interview note: String concatenation is costly.

	🔹 Optimized Approach

	Use StringBuilder (mutable).

	String str = "hello";
	String reversed = new StringBuilder(str).reverse().toString();
	System.out.println(reversed);


	⏱ Time: O(n)
	📦 Space: O(n)

	✅ 2. Check if a String is Palindrome
	🔹 Normal Approach

	Reverse string

	Compare original & reversed

	String str = "madam";
	String rev = new StringBuilder(str).reverse().toString();

	if (str.equals(rev)) {
		System.out.println("Palindrome");
	}

	🔹 Optimized Approach (Two Pointer)

	Compare start & end characters

	String str = "madam";
	int left = 0, right = str.length() - 1;
	boolean isPalindrome = true;

	while (left < right) {
		if (str.charAt(left) != str.charAt(right)) {
			isPalindrome = false;
			break;
		}
		left++;
		right--;
	}
	System.out.println(isPalindrome);


	⏱ Time: O(n)
	📦 Space: O(1)

	✅ 3. First Non-Repeating Character
	🔹 Normal Approach

	Nested loops

	Count manually

	String str = "aabbcde";

	for (int i = 0; i < str.length(); i++) {
		boolean unique = true;
		for (int j = 0; j < str.length(); j++) {
			if (i != j && str.charAt(i) == str.charAt(j)) {
				unique = false;
				break;
			}
		}
		if (unique) {
			System.out.println(str.charAt(i));
			break;
		}
	}


	⏱ Time: O(n²)

	🔹 Optimized Approach (LinkedHashMap)

	Preserves insertion order.

	String str = "aabbcde";
	Map<Character, Integer> map = new LinkedHashMap<>();

	for (char c : str.toCharArray()) {
		map.put(c, map.getOrDefault(c, 0) + 1);
	}

	for (Map.Entry<Character, Integer> entry : map.entrySet()) {
		if (entry.getValue() == 1) {
			System.out.println(entry.getKey());
			break;
		}
	}


	⏱ Time: O(n)
	📦 Space: O(n)

	✅ 6. Check if Two Strings Are Anagrams
	🔹 Normal Approach (Sort)
	String s1 = "listen";
	String s2 = "silent";

	char[] a1 = s1.toCharArray();
	char[] a2 = s2.toCharArray();

	Arrays.sort(a1);
	Arrays.sort(a2);

	System.out.println(Arrays.equals(a1, a2));

	🔹 Optimized Approach (Frequency Map)
	String s1 = "listen";
	String s2 = "silent";

	if (s1.length() != s2.length()) {
		System.out.println(false);
		return;
	}

	int[] count = new int[256];

	for (int i = 0; i < s1.length(); i++) {
		count[s1.charAt(i)]++;
		count[s2.charAt(i)]--;
	}

	System.out.println(Arrays.stream(count).allMatch(c -> c == 0));
	
	🧠 Step 0: Create the array
	int[] count = new int[256];


	What JVM does:

	Creates 256 boxes

	Each box has a number (index) and a value

	All values start at 0

	Index : Value
	108   : 0
	105   : 0
	115   : 0
	(all others also 0)


	Nothing added. No math. Just empty boxes.

	🧠 Step 1: First iteration (i = 0)
	char c1 = s1.charAt(0); // 'l'
	char c2 = s2.charAt(0); // 's'


	Now JVM converts characters to numbers automatically:

	'l' → 108
	's' → 115

	Execute this line 👇
	count[c1]++;


	Replace with real numbers:

	count[108] = count[108] + 1;


	Memory becomes:

	Index : Value
	108   : 1

	Execute next line 👇
	count[c2]--;


	Replace with real numbers:

	count[115] = count[115] - 1;


	Memory now:

	Index : Value
	108   : 1
	115   : -1


	👉 Notice:

	No 108 + 115

	Two separate boxes changed
	
	✅ Final Answer (Plain & Correct)

	It only changes the value stored at that index.
	The index itself never changes and indexes are never added together.

	Arrays.sort(arr);
	System.out.println(arr[arr.length - 2]);


	Explanation:
	Sorting works but is slower.

	🔹 Optimized Approach (Single Pass)
	int first = Integer.MIN_VALUE, second = Integer.MIN_VALUE;

	for (int n : arr) {
		if (n > first) {
			second = first;
			first = n;
		} else if (n > second && n != first) {
			second = n;
		}
	}
	System.out.println(second);


	Why better:
	No sorting → O(n) time.

	✅ 17. Find Missing Number (1 to N)

	int expectedSum = n * (n + 1) / 2;
	int actualSum = Arrays.stream(arr).sum();

	System.out.println(expectedSum - actualSum);


	Explanation:
	Missing number = expected sum − actual sum.

	🔹 Optimized Approach (XOR)
	int xor = 0;
	for (int i = 1; i <= n; i++) xor ^= i;

	System.out.println(xor);


	Why better:
	Avoids overflow risk of sum.

	✅ 20. Reverse an Array
	🔹 Normal Approach
	int[] arr = {1, 2, 3, 4};
	int[] rev = new int[arr.length];

	for (int i = 0; i < arr.length; i++) {
		rev[i] = arr[arr.length - 1 - i];
	}


	Explanation:
	Uses extra array.

	🔹 Optimized Approach (In-Place)
	int left = 0, right = arr.length - 1;

	while (left < right) {
		int temp = arr[left];
		arr[left] = arr[right];
		arr[right] = temp;
		left++;
		right--;
	}


	Why better:
	O(1) space, cleaner logic.

		if (n != 0) result[index++] = n;

	int index = 0;

	}
