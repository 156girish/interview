🔸 2. Find Duplicates in a List
        List<String> names = Arrays.asList("A", "B", "C", "A", "D", "B");
        Set<String> seen = new HashSet<>();
        List<String> nonDuplicate = names.stream()
                .filter(n -> !seen.add(n))
                .collect(Collectors.toList());
				
🔸 3. Find the First Non-Repeating Character
String input = "aabbcde";
        Optional<Character> a = input.chars()
                .mapToObj(c -> (char)c)
                .collect(Collectors.groupingBy(
                        c -> c ,
                        Collectors.counting()))
                .entrySet()
                .stream()
                .filter(n-> n.getValue()==1)
                .map(n-> n.getKey())
                .findFirst();
